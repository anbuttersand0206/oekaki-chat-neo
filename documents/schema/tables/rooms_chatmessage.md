# rooms_chatmessage

部屋内チャットのメッセージ履歴を保存するテーブル。入室時に直近50件をクライアントへ返す。

- **Django モデル**: `rooms.models.ChatMessage`
- **作成マイグレーション**: `0003_chatmessage`
- **変更マイグレーション**: `0005_auth_integration`（`user_id` VARCHAR 削除 → `user` FK 追加）

---

## カラム定義

| カラム名 | 型 | NOT NULL | デフォルト | 説明 |
|---------|---|---------|-----------|------|
| `id` | `BIGINT` | ✓ | 自動採番 | サロゲートキー |
| `room_id` | `VARCHAR(32)` | ✓ | — | 部屋ID（FK → `rooms_room.id`） |
| `user_id` | `BIGINT` | NO | NULL | 送信者（FK → `accounts_user.id`、旧メッセージは NULL） |
| `username` | `VARCHAR(20)` | ✓ | — | 送信者の表示名（非正規化。ユーザー名変更後も送信時点の名前を保持） |
| `message` | `VARCHAR(500)` | ✓ | — | メッセージ本文（最大500文字） |
| `created_at` | `TIMESTAMPTZ` | ✓ | `now()` | 送信日時（Django `auto_now_add`） |

---

## インデックス

| 名前 | 種別 | カラム | 備考 |
|------|------|--------|------|
| `rooms_chatmessage_pkey` | PRIMARY KEY | `id` | |
| `rooms_chatmessage_room_id_...` | BTREE | `room_id` | FK 検索・履歴取得用 |

デフォルトソート順は `created_at ASC`（Django `Meta.ordering`）。

---

## 外部キー

| カラム | 参照先 | ON DELETE |
|--------|--------|----------|
| `room_id` | `rooms_room.id` | CASCADE |
| `user_id` | `accounts_user.id` | SET NULL |

---

## NULL の意味

- `user_id = NULL` → 認証システム導入前に送信されたメッセージ（または将来的な削除済みユーザーのメッセージ）
- `username` は非正規化列のため、ユーザーが名前を変えても送信時点の名前が残る

---

## DDL（参考）

```sql
CREATE TABLE rooms_chatmessage (
    id          BIGINT        PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY,
    room_id     VARCHAR(32)   NOT NULL REFERENCES rooms_room(id) ON DELETE CASCADE,
    user_id     BIGINT        REFERENCES accounts_user(id) ON DELETE SET NULL,
    username    VARCHAR(20)   NOT NULL,
    message     VARCHAR(500)  NOT NULL,
    created_at  TIMESTAMPTZ   NOT NULL
);
```
