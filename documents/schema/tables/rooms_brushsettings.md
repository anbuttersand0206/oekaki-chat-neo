# rooms_brushsettings

ユーザー（ニックネーム）単位のブラシ設定を保存するテーブル。入室時にクライアントへ返し、設定変更のたびに UPSERT される。部屋をまたいで設定が引き継がれる。

- **Django モデル**: `rooms.models.BrushSettings`
- **作成マイグレーション**: `0001_initial`
- **変更マイグレーション**: `0004_brushsettings_global_per_user`（`room_id` FK 削除、`username` 単独キー化）

---

## カラム定義

| カラム名 | 型 | NOT NULL | デフォルト | 説明 |
|---------|---|---------|-----------|------|
| `id` | `BIGINT` | ✓ | 自動採番 | サロゲートキー |
| `username` | `VARCHAR(20)` | ✓ | — | ニックネーム（UNIQUE） |
| `settings` | `JSONB` | ✓ | `{}` | ブラシ設定オブジェクト |
| `updated_at` | `TIMESTAMPTZ` | ✓ | — | 最終更新日時（Django `auto_now`） |

## `settings` の JSON 構造

`serializeAllConfigs` / `deserializeAllConfigs`（`frontend/src/ui/BrushStorage.ts`）が使うフラット形式。ブラシ種別は最上位キーに直接並ぶ（`configs` 階層はない）。

```jsonc
{
  "activeType": "airbrush",   // 最後に選択していたブラシ種別
  "pen": {
    "size": 3,
    "opacity": 1.0,
    "density": 1.0,
    "spacing": 0.05,
    "hardness": 0.95,
    "mixing": 0.5,
    "water": 0.5,
    "spread": 0.3,
    "modifiers": {
      "size": {
        "pressureCurve": [{"x": 0, "y": 0}, {"x": 1, "y": 1}],
        "speedCurve":    [{"x": 0, "y": 1}, {"x": 1, "y": 1}],
        "randomAmount": 0.0
      }
      // opacity / density / spacing も同構造
    }
  },
  "airbrush": { /* 同構造 */ },
  "watercolor": { /* 同構造 */ },
  "marker": { /* 同構造 */ },
  "pencil": { /* 同構造 */ },
  "crayon": { /* 同構造 */ },
  "oil": { /* 同構造 */ },
  "pastel": { /* 同構造 */ },
  "blur": { /* 同構造 */ }
}
```

    updated_at  TIMESTAMPTZ  NOT NULL
