# rooms_brushsettings

ユーザー単位のブラシ設定を保存するテーブル。入室時にクライアントへ返し、設定変更のたびに UPSERT される。部屋をまたいで設定が引き継がれる。

- **Django モデル**: `rooms.models.BrushSettings`
- **作成マイグレーション**: `0001_initial`
- **変更マイグレーション**: `0004_brushsettings_global_per_user`（`room_id` FK 削除、`username` 単独キー化）
- **変更マイグレーション**: `0005_auth_integration`（`username` → `user_id` FK に変更）

---

## カラム定義

| カラム名 | 型 | NOT NULL | デフォルト | 説明 |
|---------|---|---------|-----------|------|
| `id` | `BIGINT` | ✓ | 自動採番 | サロゲートキー |
| `user_id` | `BIGINT` | ✓ | — | 認証ユーザーID（OneToOne FK → `accounts_user.id`） |
| `settings` | `JSONB` | ✓ | `{}` | ブラシ設定オブジェクト |
| `updated_at` | `TIMESTAMPTZ` | ✓ | — | 最終更新日時（Django `auto_now`） |

## `settings` の JSON 構造

`serializeAllConfigs` / `deserializeAllConfigs`（`frontend/src/ui/BrushStorage.ts`）が使うフラット形式。ブラシ種別は最上位キーに直接並ぶ（`configs` 階層はない）。

```jsonc
{
  "activeType": "airbrush",
  "pen": {
    "size": 3,
    "opacity": 1.0,
    "density": 1.0,
    "spacing": 0.05,
    "hardness": 0.95,
    "mixing": 0.5,
    "water": 0.5,
    "spread": 0.3,
    "modifiers": {
      "size": {
        "pressureCurve": [{"x": 0, "y": 0}, {"x": 1, "y": 1}],
        "speedCurve":    [{"x": 0, "y": 1}, {"x": 1, "y": 1}],
        "randomAmount": 0.0
      }
    }
  },
  "airbrush": { /* 同構造 */ }
  // ... 他ブラシ種別
}
```

## DDL（参考）

```sql
CREATE TABLE rooms_brushsettings (
    id         BIGINT       PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY,
    user_id    BIGINT       NOT NULL UNIQUE REFERENCES accounts_user(id) ON DELETE CASCADE,
    settings   JSONB        NOT NULL DEFAULT '{}',
    updated_at TIMESTAMPTZ  NOT NULL
);
```
